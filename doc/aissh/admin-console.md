# 管理控制台

首页为设备管理，导航另设访问授权和线路状态。顶部展示总设备数、在线设备数、管理员设备数以及双方均启用的有效授权数。设备列表支持名称、完整设备 ID、MAC、账户搜索，以及状态、角色、系统筛选和分页。机器名下方保留短 ID，同名设备可展开详情查看完整 ID 和 MAC。

连接状态使用“外网：已连接 / 未连接”“内网：已连接 / 未连接”。注册在线与隧道连接分别显示；节点同步状态和离线授权期限在“线路状态”查看。

## 管理员设备

在设备行“访问角色”点击“设为管理员”，确认设备名称和 ID 后生效。管理员设备获得访问全部其他已启用设备的单向权限，后续新注册设备也自动加入；自身不加入。禁用设备仍不可访问。新注册设备默认是普通设备，客户端不能自行申请或上报管理员身份。

管理员设备仅表示 SSH 访问角色，不提供后台登录权限，不绕过目标机器的 SSH 系统认证。此身份不会自动授予其他设备反向访问它的权限。

自动授权由香港分配固定本地端口并持久化，通过完整签名快照同步内网节点，现有客户端无需升级。已有手动授权和端口保持不变。取消管理员身份时移除自动授权并回收相关连接，原有手动授权继续保留。管理员身份存在期间不能逐条撤销自动权限；需要限制目标范围时，先取消身份，再按需手动授权。

删除目标设备会删除相关授权；若它重新注册，管理员设备会再次自动获得访问权限。内网离线时角色调整和撤销仍遵守已有最长 24 小时快照期限。

## 访问授权

添加授权仅选择普通访问端，并排除自身目标。已授权关系按访问端折叠分组；管理员分组标记自动授权，自动规则不提供单独撤销。SSH 命令可一键复制，应在对应访问端运行。
